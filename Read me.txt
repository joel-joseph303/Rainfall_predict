Kerala Rainfall Prediction System

55-Feature Production Forecast Version

A machine-learning based rainfall prediction system designed to predict
next-day and upcoming rainfall conditions for Kerala using historical
weather data, engineered weather features, and ECMWF forecast data from
Open-Meteo.

The system uses two machine-learning models:

1. Logistic Regression - Rain / No Rain Classification
2. Extra Trees Regressor - Rainfall Amount Prediction

The production system uses 55 engineered weather features.

---

Project Overview

The system performs two prediction tasks:

### 1. Rainfall Classification

Predicts whether rainfall is expected.

Output:

- RAIN
- NO RAIN
- Rain probability
- Classification threshold

The optimized classification model uses a threshold of:

0.67

2. Rainfall Regression

Predicts the expected rainfall amount in millimetres (mm).

Output:

- Predicted rainfall in mm
- Planning risk level

Forecast Data

Production predictions use Open-Meteo forecast data.

Forecast model:

ECMWF IFS 0.25°

Model identifier:

ecmwf_ifs025

The representative forecast location used by the system is:

Latitude: 10.0
Longitude: 76.125

Time zone:

Asia/Kolkata

The location represents the Kerala study area and is not intended to
represent a specific weather station.

---

Production Forecast

The production forecast script is:

Code/future_weather_55.py

It:

1. Loads the trained classification model.
2. Loads the trained regression model.
3. Loads the saved feature lists.
4. Loads the saved classification threshold.
5. Reads historical rainfall/weather data.
6. Retrieves recent model-based weather history from Open-Meteo.
7. Retrieves ECMWF forecast data.
8. Generates the required 55 features.
9. Validates the feature order.
10. Performs rainfall classification.
11. Predicts rainfall amount.
12. Produces a planning risk level.

The script does not modify the trained model files.

It also does not overwrite the historical CSV during normal forecasting.

---

Streamlit Dashboard

The interactive dashboard is:

Code/dash.py

The dashboard allows the user to select a forecast date within the
available forecast period and displays:

- Rain probability
- Predicted rainfall
- Rain / No Rain prediction
- Planning risk
- Weather information
- Model prediction information

---

Planning Risk

The production system uses the following planning-risk categories:

HIGH

Risk is HIGH when:

- Rain probability >= 80%

OR

- Predicted rainfall >= 5 mm

MEDIUM

Risk is MEDIUM when:

- Rain probability >= 50%

OR

- Predicted rainfall >= 1 mm

LOW

Otherwise the risk is LOW.

Installation

1. Clone the repository

Open a terminal and run:

git clone YOUR_GITHUB_REPOSITORY_URL

Then enter the project directory:

cd rainfall_prediction

---

2. Create a virtual environment

Windows:

python -m venv venv

Activate it:

venv\Scripts\activate

---

3. Install dependencies

pip install -r requirements.txt

---

Running the Production Forecast

From the project root:

python Code/future_weather_55.py

The program will retrieve the required forecast data from Open-Meteo
and generate the rainfall prediction.

---

Running the Dashboard

From the project root:

streamlit run Code/dash.py

A local Streamlit web application will open in the browser.

Important Path Configuration

The project is designed to use relative paths instead of personal
Windows paths.

For example, the code should use:

from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent.parent

This allows the project to work on different computers.

For example, the project can be placed at:

C:\NEEDED\rainfall_prediction

or:

D:\Projects\rainfall_prediction

without changing the model/data paths.

Forecast Backtesting

A true 24-hour forecast backtest was performed for 2025 using the
Open-Meteo Previous Runs API and ECMWF IFS 0.25° archived forecast data.

The backtest used:

- Forecast lead time: 24 hours
- Forecast model: ECMWF IFS 0.25°
- Period: 2025
- Rainfall threshold: 1.0 mm
- Representative location: 10.0° N, 76.125° E

True forecast backtest results:

Classification

- Accuracy: 0.8407
- Precision: 0.6515
- Recall: 0.8776
- F1-score: 0.7478
- ROC-AUC: 0.9272

Regression

- MAE: 0.7529 mm
- MSE: 0.9974
- RMSE: 0.9987 mm
- R²: 0.4715

These results represent true archived 24-hour forecast performance.

The model-development validation results reported earlier in this
README are separate from the true forecast backtest and should not be
interpreted as real-world forecast performance.

---

Rainfall Classification Threshold

The rainfall class is based on a rainfall threshold of:

1.0 mm

Therefore:

Rainfall >= 1.0 mm → RAIN

Rainfall < 1.0 mm → NO RAIN

The production Logistic Regression probability threshold is:

0.67

---

Notes

- Forecast values are obtained from Open-Meteo.
- The production forecast uses ECMWF IFS 0.25°.
- The representative coordinate is used for the Kerala study area.
- Recent model-based weather history is used to construct lag and
  rolling features required by the 55-feature model.
- The production system does not overwrite trained model files.
- The production system does not overwrite daily_weather.csv during
  normal forecasting.
- Internet access is required when running the production forecast or
  Streamlit dashboard because forecast data is retrieved from
  Open-Meteo.

---

Limitations

The system should be considered a machine-learning forecasting
prototype rather than an official meteorological forecasting service.

Rainfall is highly variable in space and time, particularly during
Kerala's monsoon seasons.

The model uses a representative coordinate rather than a dense
station-specific forecast.

Forecast performance can vary depending on weather conditions,
forecast-model errors, and changes in rainfall patterns.
